# S03 完整请求对照

> Set the air conditioner temperature to 24 degrees Celsius.

五组使用同一条 Query、同一完整 Command Set 和相同合法取值。以下文件是冻结的实际请求：

- [baseline](S03.baseline.request.json)
- [criteria_only](S03.criteria_only.request.json)
- [rules_only](S03.rules_only.request.json)
- [combined](S03.combined.request.json)
- [two_stage](S03.two_stage.request.json)

`two_stage` 文件是第一步的30个适用性问题。第二步的 Key 由各模型的第一步实际输出决定，完整实际请求保存在各模型 formal_receipts.jsonl 的 stages[1].payload。若全部 omit，则不发第二次请求。

下面展示温度单位这个问题的改写；每个上方JSON文件都包含完整 state 和所有30道问题。

## rules_only

```json
{
  "type": "choice",
  "instructions": "Choose the required temperature unit. A Celsius setpoint requires value 0; a Fahrenheit setpoint requires value 1, even when no separate unit-change command is spoken. Otherwise follow an explicitly requested unit change. Choose omit only if no setpoint and no unit change is requested.",
  "criteria": {
    "omit": "Do not send t_temp_type: Temperature Unit is not requested.",
    "0": "Set Temperature Unit to Celsius.",
    "1": "Set Temperature Unit to Fahrenheit."
  }
}
```
