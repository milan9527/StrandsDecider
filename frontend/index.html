A SMALL, FAST DECISION MODEL

得到结构化答案。

基于 Qwen3.5-2B 主干，用 Pointer head 替换语言生成头。模型对候选选项评分，无需逐个生成输出 token。

ChoiceNoulScore

概率与 confidence 有区别

Choice 的 confidence 是归一化后的最高概率：(N × p_max − 1) / (N − 1)。它不等于获胜选项的概率。Score 的 confidence 基于分布离散程度。

Noul 返回 P(true)

越接近 1 越倾向“是”，越接近 0 越倾向“否”，接近 0.5 则不确定。Noul 没有单独的 confidence 字段。

同一上下文，多种问题

模型支持共享前缀的批量推理。本演示为测量每项耗时，分别执行各个问题，因此可能更慢。总时间包含网络与排队；实际耗时取决于设备、上下文长度和问题数量。

在本地运行真实模型

Web 演示本身不需要 API Key。真实模型首次启动会下载约 4.5 GB 基座权重与适配器，需要访问 Hugging Face。

默认复现博客中的 v19；可用 DECIDER_MODEL 指向其他官方检查点。 

# 终端 1：启动模型（默认 CPU）
bash scripts/serve_model.sh

# 终端 2：启动演示页面
uv run python -m scripts.manage_users create admin
AUTH_COOKIE_SECURE=false uv run uvicorn app.main:app --port 8000
