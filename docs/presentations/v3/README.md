## 数据口径

复用 **2026-10-10 12:26 UTC 起**的真实模型采集与当前 `crypto10` 界面截图，本次重排没有重新调用模型。源数据见 [固定输入记录](../../results/benchmark-2026-10-10.json)、[闭环记录](../v2/loop-observations.json) 和 [截图记录](../v2/capture-manifest.json)。

- 固定输入：每侧尝试 20 次，19 组成功同输入配对。Decider 合计 **1.810 s**，GPT **22.068 s**，比值约 **12.20×**。
- GPT 另有 1 次 `ReadTimeoutError`，该侧结算方案未执行。成功配对速度图排除失败请求，也排除对应的 Decider 请求；结算图因此只有 4 对。
- 节点图使用平均耗时：客服、核验、审批、结案各 4 对，处置 3 对。
- 闭环：USDC 每侧 6 次决策、1 个模拟事件；退款每侧 9 次决策、2 个模拟事件。双方均完成模拟业务。后续输入可能不同，不混入固定配对统计。
- 时间为 `backend_total_ms` 的求和或均值，包括服务通信与排队；不是浏览器全程用时，不包括现实外部事件等待。
- 演示参考是开发者策略，不是通用准确率。BERT 未进行性能实测；候选概率不等于业务正确率。

图表、流程、数值与说明以 PowerPoint 文本和形状生成；截图与图标以高分辨率图片嵌入。图标来源及许可见 [icons](icons/README.md)。所有页面的详细来源写入演讲者备注和讲稿。

## 重新生成

在仓库根目录执行，使用已入库的 v2 文稿、采集记录与图标：

```bash
uv run --with python-pptx --with pillow --with cairosvg \
  python scripts/build_presentation_v3.py

libreoffice --headless --convert-to pdf --outdir docs/presentations/v3 \
  docs/presentations/v3/Strands-Decider-模型原理与支付业务演示-v3-25页-20261010.pptx
```

输出记录于 `build-manifest.json`，PDF 页数、文本完整性及边界检查见 `render-audit.json`。不需要 AWS 或演示账号凭据。
